# WEMS - Project Overview

## What is WEMS?
WEMS is a **small desktop application** for tracking employee driving and operating licenses for a warehouse environment.

## Core Entities

### 1. Warehouses (Entrepots)
- Physical warehouse locations
- Base organizational unit

### 2. Employees
- Workers employed at warehouses
- Tracked for certification compliance

### 3. Certifications & Documents
- **CACES** - Technical operating licenses (e.g., forklift licenses)
- **Medical Visits** - Health checkups/examinations
- **Online Training** - E-learning courses completed
- **Signed Driving Authorizations** - Official authorization documents

### 4. File Storage
- Local file storage capability for documents

## Key Features

1. **Data Export** - Export data for reporting/backup
2. **Onboarding Database** - Track new employee onboarding
3. **Alerts System** - Notifications for expiring certifications
4. **Statistics Dashboard** - Analytics and reporting
